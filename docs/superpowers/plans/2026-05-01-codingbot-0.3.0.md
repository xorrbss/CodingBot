# CodingBot 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 0.2.0 위에 관측(metrics) 사이클 적용. `state.json` 카운터 세분화(judge source / stop outcome / judge call telemetry) + `JudgeTimeout` 분리 + `codingbot status` 출력 섹션화.

**Architecture:** `state.py`에 신규 `record_*` 6개 + `_initial_state` 키 12개 추가. `llm_judge.py`에 `JudgeTimeout(JudgeError)` 서브 예외 + `_call`에서 `anthropic.APITimeoutError` 매핑. 두 hook(`auto_approve`, `handoff_or_continue`)에서 분기마다 명시적으로 카운터 호출. `cli.py`의 `_cmd_status`만 섹션화. 새 모듈/외부 의존/의존 그래프 변경 **없음**.

**Tech Stack:** Python 3.11, pytest 8, pytest-mock, portalocker, anthropic SDK.

**Spec:** `docs/superpowers/specs/2026-05-01-codingbot-0.3.0-design.md`

**Base:** `v0.2.0` (commit `3434973`)

def record_auto_approve_by(judge: str) -> None:
    """PreToolUse approve의 source 분기 카운터.

```python
def _call(system: str, user: str) -> str:
    cfg = config.load()
    try:
        resp = _client().messages.create(
            model=cfg.judge_model,
            max_tokens=300,
            timeout=cfg.judge_timeout_secs,
            system=system,
            messages=[{"role": "user", "content": user}],
        )
    except Exception as e:
        import anthropic  # _client()에서 이미 import된 상태이므로 추가 비용 없음
        if isinstance(e, anthropic.APITimeoutError):
            raise JudgeTimeout(f"API call timed out after {cfg.judge_timeout_secs}s") from e
        raise JudgeError(f"API call failed: {e}") from e
    try:
        return resp.content[0].text
    except (IndexError, AttributeError) as e:
        raise JudgeError(f"unexpected response shape: {e}") from e
```
